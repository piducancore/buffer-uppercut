# Buffer Uppercut DSP regression corpus v3: unified Filter

`dsp-contract-v3-unified-filter` is the canonical audio corpus for the unified
Filter effect approved in
[`docs/adr/0008-unified-filter-effect.md`](../../docs/adr/0008-unified-filter-effect.md).

The input signals, block timing, held masks, tempo, pitch, and serial scenarios
come from the frozen v2 corpus. The generation step translated the former
low, mid, and high filter types into one Filter type with Low-pass, Band-pass,
and High-pass Mode values, renumbers LoFi and Vinyl, and captures expected
outputs from the current Rust engine. V1 and v2 remain frozen.

Processing files use `BUDSP_CONTRACT\t3`. Pitch actions use
`BUDSP_PITCH_ACTIONS\t3`. Outputs must be finite and satisfy:

```text
abs(actual - expected) <= 1e-7 + 1e-7 * abs(expected)
```

Verify from the repository root:

```sh
(cd contract/v3 && shasum -a 256 -c SHA256SUMS)
cargo test -p buffer-uppercut-dsp --test contract
```

V3 is frozen and is not regenerated by the current engine.
