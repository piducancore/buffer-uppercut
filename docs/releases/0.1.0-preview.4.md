# Buffer Uppercut 0.1.0-preview.4

Unsigned preview 4 makes direct performance input configurable and recordable.
The 16 pads still default to `1234/QWER/ASDF/ZXCV`, but the native editor now
offers Learn, Clear, Reset Layout, and an explicit conflict swap. Pointer and
direct-key pad holds drive the existing pad Trigger host parameters as combined
gestures, so a host can record and replay them. MIDI holds remain independent.

The durable physical-key map is shared by host state and native `.bupreset`
version 3. It is not a host parameter: the fixed automatable schema remains 144
parameters at IDs `1..144`. Recalled high Trigger values are suppressed until a
fresh press/event, preserving the host snapshot while preventing an old held
performance from sounding when a project opens.

## Downloads and source

- Linux x86-64: CLAP and VST3, built on Ubuntu 22.04.
- Windows x86-64: CLAP and VST3, built on `windows-2022`.
- macOS Apple silicon: CLAP and VST3, built on the arm64 `macos-14` runner.
- Standalone is a development host and is not distributed.
- Source revision: the commit identified by tag `v0.1.0-preview.4` in
  https://github.com/piducancore/buffer-uppercut.

Linux targets glibc-based x86-64 distributions and may require the host's audio,
font, graphics, udev and X11 runtime libraries. Linux has not been tested in a
real DAW; LMMS does not natively host these CLAP/VST3 formats.

## Validation and accepted preview limitations

This candidate passed local formatting, Clippy, workspace and allocation-paranoid
tests, all five deterministic screenshot checks, and installed CLAP Validator.
The release workflow validates the exact tagged CLAP/VST3 bundles on all three
platforms with CLAP Validator and pluginval before packaging them.

Real-DAW acceptance for this exact input increment remains open: Ableton Live
and REAPER recording/replay, save/reopen, mapping-only project dirty state and
host automation modes still need coverage. Rapid taps within one processing
block can collapse, so this preview does not claim lossless capture. Local VST3
pluginval was unavailable; the release workflow provides that exact-artifact
check. The detailed checklist is in `docs/TESTING.md`.

These are unsigned previews: Windows Authenticode signing, macOS Developer ID
signing and macOS notarization are absent. Operating systems or DAWs may warn
about or block installation. Follow `INSTALL.txt` inside each package; do not
disable antivirus or system-wide security protections. Use a test project.
`SHA256SUMS` verifies file integrity but is not a publisher signature.
