# Buffer Uppercut 0.1.0-preview.2

Unsigned preview 2 adds an x86-64 Linux package. The plugin behavior is
unchanged from preview 1.

## Downloads

- Linux x86-64: CLAP and VST3, built on Ubuntu 22.04.
- Windows x86-64: CLAP and VST3, built on `windows-2022`.
- macOS Apple silicon: CLAP and VST3, built on the arm64 `macos-14` runner.
- Standalone is a development host and is not distributed.

The Linux build targets glibc-based x86-64 distributions and may require the
host system's audio, font, graphics, udev and X11 runtime libraries. It has not
been tested in a real Linux DAW. LMMS does not currently host CLAP or VST3
natively, so this package is not advertised as compatible with LMMS.

## Validation

The tagged source must pass formatting, Clippy, workspace tests, deterministic
DSP contracts and allocation-paranoid tests. Every platform then builds the
exact CLAP/VST3 bundles, runs CLAP Validator and pluginval, checks the reviewed
dependency-notice inventory, and only then creates the draft ZIPs.

Buffer Uppercut was used actively throughout a weekend in Ableton Live on
macOS and Windows without a reported crash. That experience used development
builds rather than these exact ZIPs. Linux has automated validation only; this
preview deliberately accepts and discloses that limitation.

## Important limitations

These packages are unsigned previews. Windows Authenticode signing, macOS
Developer ID signing and macOS notarization are absent. The operating system or
DAW may warn about or block installation. Do not disable antivirus or
system-wide security protections. Use a test project and low monitoring volume.

Detailed automation, CPU, keyboard-layout, GUI and real-host acceptance items
remain open, so this is not a stable release. See `INSTALL.txt` inside the
package. `SHA256SUMS` verifies file integrity but is not a publisher signature.
