# Buffer Uppercut 0.1.0-preview.1

First public unsigned preview of the canonical Rust/TRUCE implementation.

## Downloads

- Windows 64-bit: CLAP and VST3, built on `windows-2022`.
- macOS Apple silicon: CLAP and VST3, built on the arm64 `macos-14` runner.
- Linux is not included because it has not completed a real-host smoke test.
- Standalone is a development host and is not distributed.

## Validation

The tagged source must pass formatting, Clippy, workspace tests, deterministic
DSP contracts, allocation-paranoid tests, CLAP Validator and pluginval before
GitHub creates the draft. Buffer Uppercut was also used actively throughout a
weekend in Ableton Live on macOS and Windows without a reported crash. That
experience used development builds, not the final ZIP files produced by this
tag; this preview accepts that limitation and relies on the release validators
for the exact generated bundles.

## Important limitations

These packages are unsigned previews. Windows Authenticode signing, macOS
Developer ID signing and macOS notarization are absent. The operating system or
DAW may warn about or block installation. Do not disable antivirus or
system-wide security protections. Use a test project and low monitoring volume.

Only Ableton Live use on macOS and Windows is recorded as real-host evidence.
CLAP receives automated validator coverage but is not claimed to have the same
weekend-long Ableton coverage. Several detailed automation, CPU, keyboard-layout
and host acceptance items remain open, so this is not a stable release.

See `INSTALL.txt` inside the package for installation and first-use guidance.
`SHA256SUMS` verifies file integrity but is not a publisher signature.
