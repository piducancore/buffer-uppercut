# Buffer Uppercut 0.1.0-preview.5

Unsigned preview 5 expands Beat Repeat's Cell divisions with `1/3`, `1/6`,
`1/12`, `1/24`, dotted `3/16`, and quintuplet `1/5`. All 15 choices appear in
ascending duration. Reverse, Tape Stop, and Gate keep their existing straight
grids. Factory kits retain their intended musical durations.

Key mapping controls now sit below the selected pad's knobs. This release keeps
the existing native editor and fixed slot-order audio chain. The compact UI
concepts, press-ordered processing, and background keyboard takeover are not
part of this release.

## State and automation

The expanded Cell scale deliberately changes the interpretation of previously
saved normalized Cell values and automation. Old projects/presets can therefore
select a different Repeat duration; check those settings before use. No migration
is provided. Parameter IDs, the 144-parameter count, and `.bupreset` version 3
remain unchanged.

## Downloads and source

- Linux x86-64: CLAP and VST3, built on Ubuntu 22.04.
- Windows x86-64: CLAP and VST3, built on `windows-2022`.
- macOS Apple silicon: CLAP and VST3, built on the arm64 `macos-14` runner.
- Standalone is a development host and is not distributed.
- Source revision: the commit identified by tag `v0.1.0-preview.5` in
  https://github.com/piducancore/buffer-uppercut.

Linux targets glibc-based x86-64 distributions and may require the host's audio,
font, graphics, udev and X11 runtime libraries. Linux has not been tested in a
real DAW; LMMS does not natively host these CLAP/VST3 formats.

## Validation and accepted preview limitations

DSP tests cover all six added divisions at multiple tempos, including CELL
lookback. The frozen audio regression references remain unchanged; test inputs
translate the historical Cell scale. The release workflow gates packaging on
formatting, Clippy, workspace and allocation-paranoid tests, exact-bundle CLAP
Validator/pluginval checks, and third-party notice inventory checks on all three
platforms.

Listening, Cell automation replay, and save/reopen acceptance of these added
divisions in a real DAW remain pending. Earlier user feedback confirms pad and
knob recording in Ableton Arrangement View with Automation Arm enabled, not
complete acceptance of these exact release artifacts. Rapid taps within one
processing block can collapse. See `docs/TESTING.md` for the remaining checks.

These are unsigned previews: Windows Authenticode signing, macOS Developer ID
signing and macOS notarization are absent. Operating systems or DAWs may warn
about or block installation. Follow `INSTALL.txt` inside each package; do not
disable antivirus or system-wide security protections. Use a test project.
`SHA256SUMS` verifies file integrity but is not a publisher signature.
